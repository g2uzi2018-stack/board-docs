# DX-SMART DX-PJ15-V1.1 Type-C 转 TTL 串口模块

![实物](photo.jpg)

大夏龙雀（DX-SMART）的 USB 转串口小板，外壳透明，丝印 `Type-C>>TTL`、`DX-PJ15-V1.1`。用于电脑和 ESP32 / GNSS / 4G 模块之间的串口调试，不占 ESP32 的 GPIO。

## 引脚（照片丝印，排序以实物为准）

| 引脚 | 说明 |
|---|---|
| 3V3 | 3.3 V 输出（电流能力待确认，别给 4G 模块供电）|
| 5V | USB 5 V 直通输出（两个焊盘）|
| GND | 地（丝印另有 `NC` 字样，具体是哪一脚待确认）|
| RX | 模块接收 ← 对方 TX |
| TX | 模块发送 → 对方 RX |

## 电气与注意

- USB 桥接芯片：**待确认**。外壳挡住了芯片丝印，大夏龙雀官网也没找到 PJ15 的产品页（常见方案是 CH340 / CH343 / CP2102）。插上电脑后看设备管理器里的 VID:PID 就能知道。
- TTL 电平是 3.3 V 还是 5 V（或有没有切换跳线）：**待确认**。接 ESP32-S3 前先用万用表量 TX 空闲时的电平，必须是 3.3 V。
- 交叉接线：TX→RX，RX→TX，GND 共地。

## 和 YD-ESP32-S3 一起用

- 板子自带 USB 口，平时不需要这个模块。它主要用来：抓 GNSS / 4G / RS-485 等模块的原始串口数据；或者接 ESP32 的 UART0（GPIO43 TX / GPIO44 RX）看日志。
- 接 UART0 时：模块 RX 接 GPIO43，模块 TX 接 GPIO44，GND 接 G。不要同时用 5V/3V3 脚和板子 USB 一起供电。
