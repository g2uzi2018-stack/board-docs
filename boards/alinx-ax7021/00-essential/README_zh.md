## 开板最小路径

1. 读用户手册：电源、JTAG、串口、启动模式（JTAG / QSPI / SD / eMMC）。
2. 对照底板原理图确认 5 路网口与扩展座引脚。
3. 按官方 `AX7021B_2023.1` 跑第一个 LED / UART / 单网口例程。
4. 再碰多网口、HDMI、摄像头 / AD 扩展模块。
